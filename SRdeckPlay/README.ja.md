# SRdeckPlay

アナログプラグインで保存した狭帯域IQ録音を再生する、SRdeckとは独立したWindows x64アプリです。SRdeck本体・SDR機器・プラグインのインストールは不要です。

## 起動

.NET 10 SDKを使用し、リポジトリのルートで実行します。

```powershell
dotnet build SRdeckPlay\SRdeckPlay.csproj -c Release
.\SRdeckPlay\bin\Release\net10.0-windows\win-x64\SRdeckPlay.exe
```

コマンドライン引数にWAVのパスを1つ渡すか、画面の「IQ WAVを開く」、ドラッグ＆ドロップで録音を開けます。ビルド出力フォルダー一式を使用してください。実行には.NET 10 Desktop Runtimeが必要です。

## 入力と表示

- 16 bit PCMステレオWAV（左=I、右=Q）。アナログ録音の同名JSONを同じフォルダーに置くと中心周波数・方式・帯域などを読み込みます。
- 同じ`RecordingId`の公開済み分割WAVを番号順に連続再生します。途中ファイルを選択しても、同じフォルダーの同一録音をまとめて開きます。分割ファイルの欠落は赤いマーカーで表示します。重複・サンプル位置の重なり・JSONとWAVの不一致はエラーになります。
- サンプルレートは48 kHz～2 MHz。分割途中でサンプルレートが変わる録音には対応していません。欠落時間は無音で補完せず保存サンプル順に扱い、不連続点で実時刻表示が切り替わります。
- 上部約1/4が録音全体のRSSIと横方向ウォーターフォール、左下が幅380 px固定のコントロール、右下が帯域制限後のIQスペクトラムとウォーターフォールです。小さいウィンドウでは左下を縦スクロールできます。
- 全体表示は横=録音した実時刻、縦=録音中心からの周波数。RSSIは1秒ごとの平均電力をキャッシュし、表示範囲に集約します。FFTは150 ms以上300 ms未満になるサンプル数のHann窓を使い、100 msごとに計算して1秒ごとにピーク集約し、256周波数ビンへまとめます。分割WAVの末尾では、次ファイルの先頭サンプルもFFT窓に含めます。
- FFTとRSSIの解析結果はWAVと同じフォルダーに`<WAVファイル名>.fftcache`として保存し、1 dB刻みの8 bit値で記録します。FFT・RSSIともに録音時の校正後dBm値です。スペクトルは1秒あたり256 byte、RSSIは1秒あたり1 byte（合計約15.4 kB/分）で、別途ヘッダー等が加わります。手動校正は表示時に差分を適用します。次回以降の表示範囲変更と再オープンでは再利用し、WAVまたはJSONのサイズ・更新日時が変わると再解析します。
- 上部タイムラインはドラッグまたはトラックパッドの横スワイプで左右に移動し、クリックで再生位置へ移動します。Ctrl+ホイールで時間軸を拡大縮小し、＋／−でも操作できます。RSSI上のホイールで縦方向を移動し、水色のスケルチ線をドラッグするとレベルを変更できます（再生中にも反映）。スペクトログラム上のホイールは明るさ調整です。スクロールバーで時間を移動し、「全体」で全時間を表示します。範囲変更では1秒単位のRSSIキャッシュとFFTキャッシュを再利用します。
- スペクトラムの青い線と塗り、10 dBグリッド、ウォーターフォールのLUT、周波数グリッド計算はSRdeckのソース・定数を共有します。上部スペクトログラムは表示範囲内の最弱値を黒の基準にします。右下の電力範囲は−40～−140 dBm、色の基準ノイズフロアは−120 dBmです。
- 表示は`Timeline`に記録されたdBFS→dBm換算値を使用します。校正値がない場合は、SRdeckの受信テレメトリーの既定補正−80 dBによる「参考dBm」と明示します。「dBm換算補正」に値を入力して「適用」すると手動校正、空欄で録音時の校正に戻ります。
- 「スキップ再生」は初期状態で有効です。RSSIがスケルチレベルより2 dB低いと音声をミュートし、閉状態が3秒続くと録音を先読みして次にレベルを2 dB以上超える位置の1秒前へ移動し、短いビープ音を鳴らします。次の開きがなければ録音末尾へ移動します。スケルチレベルは−150～0 dBmで設定でき、初期値は−100 dBmです。上部RSSIグラフに水色の破線で表示します。
- 時刻はJSONに保存したUTCとサンプル位置から求め、Windowsのローカル時刻とタイムゾーンで表示します。日付は上部・再生時刻欄、時分秒は各グラフに表示します。時刻が未記録なら「録音時刻なし」と表示します。
- `Timeline`に記録された不連続位置を縦線で表示します。上部の「不連続線」チェックボックスで表示を切り替えられます。一覧を選ぶとその位置へ移動します。
- 右下はIQ通過帯域を適用する前後の4096点FFTを重ねて表示します。制限前を半透明の灰色、復調器の12次Butterworthチャンネルフィルター通過後を青色で手前に描き、帯域の変化を比較できます。帯域端は−3 dB、帯域外は約72 dB/octで減衰します。FFTは間引き後・音声復調前のIQから計算し、サンプルレートに合わせて周波数軸へ配置します。縦方向ウォーターフォール（最新が上）にもフィルター後のスペクトルを表示します。スペクトラムとウォーターフォールの高さは1:2です。同調位置を0 Hzにして通過帯域の周囲を拡大し、IQ上下限の線と帯域外の塗り、Hzラベルを重ねます。周波数幅は変調方式の選択時に標準幅へ戻り、その後はCtrl+マウスホイールまたはトラックパッド操作で調整します。IQ上下限の変更では周波数幅は変わりません。上下限線はドラッグで100 Hz刻みに調整できます。

更新版のアナログプラグインは、JSONスキーマ2の`Timeline`にサンプル位置・実時刻・校正変更・不連続点を保存します。SRdeckPlayはこのタイムラインを使用します。

## 再生と復調

- 再生／一時停止／停止（先頭へ戻る）。上部タイムラインをクリックするとその時刻へ移動し、再生中なら再生を継続します。
- Space: 再生・一時停止、左右矢印: 5秒移動。テキスト入力中は通常の編集操作になります。
- AM／FM／USB／LSBを選択できます。「方式の標準帯域」で入力欄を初期化し、「適用」で変更します。再生中にも変更できます。
- 同調オフセットは録音中心からのHz。IQ下限・上限は同調位置を0 Hzとする相対周波数です。USBの例は+250～+3000 Hz、LSBは−3000～−250 Hzです。下限は上限より小さく、帯域幅100 Hz以上、録音のナイキスト範囲内に指定します。
- SRdeckのアナログ復調器をソース共有しています。音声処理は既存の方式ごとの特性（AMのAGC、FMのデエンファシス／広帯域時のステレオ、SSBの音声選択）を引き継ぎます。IQ帯域の変更で、録音時に既に除去された周波数成分は復元できません。
- 出力は48 kHzステレオでWindowsの既定出力先へ送ります。音量・ミュートはWindowsの音量ミキサーでSRdeckPlayを操作してください。

## 検証

```powershell
dotnet run --project tests\SRdeckPlay.Tests\SRdeckPlay.Tests.csproj -c Release
```

合成IQによるAM/FM/USB/LSBの1 kHz音声復元、出力時間、非対称帯域の抑圧、FFT周波数とレベル、RSSI、分割境界シーク、不正WAV、解析キャンセル、再生停止、WPF画面の読み込みを検証します。第1引数にPNGの出力パスを指定すると画面プレビューも保存します。

`--audio-smoke`を追加すると、Windowsの既定出力先へ50 msの無音データを送り、音声バッファの投入・再生完了も確認します。

`--benchmark`では、262,144点FFTの256ビンへの集約を30回、ウォーターフォールの更新を320回計測し、処理時間・マネージドメモリの割り当て量・GC後の保持量を出力します。

```powershell
dotnet run --project tests\SRdeckPlay.Tests\SRdeckPlay.Tests.csproj -c Release -p:Platform=x64 -- --benchmark
```

ウォーターフォールは循環する画像の最新1行だけを更新し、履歴には時刻だけを保持します。FFTキャッシュ作成では出力バッファを再利用し、ピーク集約後にdBへ変換します。
